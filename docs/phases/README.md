# Phase logs and retrospectives

Each phase gets two things in this folder:

- **A live log while the phase is in progress** (`phase-N-log.md`) — updated in small increments as work actually happens: what's done, what's next, decisions made, blockers hit. This is what lets anyone — including a future me, in a different session or after a gap of weeks — reconstruct exactly where things stand without relying on memory of a past conversation.
- **A short retrospective once the phase is finished** (`phase-N-retrospective.md`) — what was built, what broke, what I'd do differently. The live log's content folds into this once the phase closes, and a fresh log starts for the next phase.
